보이드노트 — 회의 원문을 기기 밖으로 새지 않게 쌓는 녹음 앱

iPhone이 녹음하고 글로 바꾸고, 결과는 회사가 정한 주소 한 곳으로만 보냅니다. 앱은 요약하지 않습니다. 총 30개 화면(iPhone 393×852). 모든 말은 한국어, 더미 데이터는 가상 회사 ‘한결’의 회의입니다.

구조 1 · 시작과 종료는 앱 밖에서잠금 화면·제어 센터·위젯에서 탭 1회로 시작. 경고와 자동 정지는 Live Activity·알림으로 앱 밖에 나옵니다. 잊어도 몇 시간씩 이어지지 않습니다.
구조 2 · 녹음 화면은 1초 판독시간·소리·자막 3개만. 소리가 안 들어오면 녹음은 유지한 채 알립니다.
구조 3 · ‘어디로’가 어디서나 보인다목록 상단 줄, 상세의 ‘보낸 내용 보기’, 전송 기록의 실제 본문까지 같은 원본 하나로 연결됩니다.
① 처음 시작하기② 앱 밖 시작·정지③ 녹음 중④ 목록·결과⑤ 전송 기록⑥ 설정

① 처음 시작하기

앱이 하는 일 → 녹음 동의 → 마이크 → 모델 받기(630MB를 보여 주고 사용자가 누른 뒤에만). 회사 주소는 여기서 묻지 않고 설정으로 미룬다.

② 앱을 열지 않고 시작·확인·정지 (유저스토리 1)

핵심 구조 결정 1. 시작은 잠금 화면 컨트롤·제어 센터·홈 위젯·액션 버튼 중 어디서든 탭 1회. 녹음 중·자동 정지 경고·변환 진행은 모두 Live Activity와 알림으로 앱 밖에 나온다.

③ 녹음 중 슬쩍 보기 (유저스토리 2)

핵심 구조 결정 2. 시간·소리·자막 3개만. 책상 위에서 곁눈으로 읽히도록 56pt 숫자, 어두운 면. 자막은 ‘미리보기’임을 화면에 명시.

④ 회의 목록과 결과 (유저스토리 3)

상태는 색+아이콘+글자. 실패 행에는 ‘기기에 그대로’와 다음 시도 시각이 목록에서 바로 읽힌다. 상단 초록 줄은 ‘어디로 나가는가’를 매 화면 한 줄로 반복하고 전송 기록으로 연결.

⑤ 전송 기록 — 보낸 것 증명 (유저스토리 4)

핵심 구조 결정 3. 한 화면에서 ‘회의 원문이 나간 주소 1곳, 오디오 0건’을 요약하고, 요청마다 시각·주소·결과·원문 포함 여부를 보여 준다. 상세에서는 실제 보낸 본문을 그대로 볼 수 있다.

⑥ 설정

주소·연결 확인, 무음 자동 정지 시간, 전송 기록, 라이선스·방침. ‘연결 확인’이 무엇을 보내는지 버튼 바로 아래에 적는다.
