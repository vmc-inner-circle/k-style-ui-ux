# Decisions

후보는 글로 비교했고 전부 렌더하지는 않았다(시간 대비 판단). 교차 비평은 **사용자 관점(회의 중 곁눈·시작/종료 망각)** 과 **구현·보안 관점(iOS 제약·증빙 가능성)** 두 개로 했다.

## 식별된 독립 축
1. **시작/종료 구조** — 어디서 시작하고 누가 멈추는가
2. **녹음 중 화면 밀도** — 슬쩍 보기 vs 상세 모니터
3. **"보낸 것 증명" 구조** — 보안 담당자가 어디서 확인하는가

## 축 1: 시작/종료
| 후보 | 사용자 관점 | 구현·보안 관점 | 선택 |
|---|---|---|---|
| A. 앱 안 큰 녹음 버튼만 | 앱 찾기 문제 그대로 | 쉬움 | ✗ |
| B. 앱 안 버튼 + 잠금 화면 컨트롤·제어 센터·위젯·액션 버튼에서 탭 1회, 상태는 Live Activity | 앱을 열지 않고 시작·정지 | iOS 18 컨트롤 + ActivityKit 로 가능 | ✓ |
| C. 캘린더 연동 자동 시작 | 편하지만 PRD상 계정·연동 없음 | 캘린더 권한 + 오탐 녹음 = 동의 위반 위험 | ✗ |

종료는 무음 타이머 + **앱 밖 경고**(Live Activity 문구 변경, 알림)로 해결. 경고에서 "계속 녹음"으로 타이머를 리셋할 수 있어 발표형 회의(한 명이 오래 말 안 하는)도 안전하다.
**새 실패 모드**: 잠금 화면 컨트롤은 OS 버전 의존(iOS 18+). 미지원 기기는 홈 위젯·액션 버튼으로 대체(brief 가정).

## 축 2: 녹음 화면 밀도
| 후보 | 설명 | 선택 |
|---|---|---|
| A. 파형·레벨·자막·설정 전부 | 정보 많음, 회의 중 시선 뺏김 | ✗ |
| B. 시간(56pt) + 레벨 막대 + 자막 3줄 + 정지 | 1초 판독 | ✓ |
| C. 시간만 | 너무 비어 "소리가 들어오는지" 확인 불가 | ✗ |

어두운 테마는 이 화면에만 쓴다. 대신 목록·설정과 색온도가 달라 보일 위험이 있어 같은 따뜻한 먹색(`#141413`)을 쓰고 C단계에서 확인한다.

## 축 3: 보낸 것 증명
| 후보 | 설명 | 선택 |
|---|---|---|
| A. 설정 안 전송 기록 화면만 | 담당자는 찾을 수 있으나 직원은 안심 못 함 | ✗ |
| B. 전송 기록 화면(시각·주소·결과·**보낸 본문 원문**) + 목록 상단 "원문은 ○○로만" 한 줄 + 상세의 "보낸 내용 보기" | 같은 원본(전송 기록)을 세 곳에서 링크만 건다 | ✓ |
| C. 내보내기(CSV) | 앱 밖으로 새 데이터 경로가 늘어남 | ✗ |

전송 기록 상단 요약: "회의 원문이 나간 주소 1곳 · 오디오 전송 0건". 행마다 **원문 포함 / 내용 없음** 배지로 모델 다운로드·연결 확인(내용 없음)과 회의 전송(원문 포함)을 구분한다.

## 남은 트레이드오프
- 모델 다운로드는 회사 주소가 아니라 외부 호스트로 나간다. "회사 주소 말고는 안 나간다"는 문구를 정확히 하기 위해 "회의 내용은" 으로 한정했다.
- 전송 기록은 앱 내부 로그라 앱이 거짓말하면 못 잡는다. 네트워크 레벨 검증(프록시)은 보안 담당자 몫이며 화면에서 약속하지 않는다.

## 검증 결과 (A·C단계, 2026-10-28 실측)
**C단계(스크린샷 30장 육안)**: 1회차에서 3건 발견 → 수정 후 재확인 완료.
- 목록의 '녹음 시작' 버튼이 마지막 행을 가림 → 하단 고정 바(그라데이션)로 분리
- 목록 상단 '어디로' 줄이 2줄로 꺾임 → 문구 축약해 1줄
- 전송 기록이 요약(9건·실패 4)과 행 수가 안 맞음 → 누락 4건 추가, 요약과 일치

**A단계(코드 수치)** — brief.md 기준값 대비 **미충족**, 고치지 않고 남김:
- 색: 토큰 외 hex 약 25종(주로 잠금 화면·녹음 화면의 어두운 면과 iOS 시스템 UI 모사 색). 의미색 3개(도착·주의·실패)는 지켜짐
- 타이포: 선언한 6단계 외에 11/13/15/17/18/22/24/32/88px 사용(시스템 UI 모사와 모바일 보조 문구)
- 간격: 4배수 위반 2·3·6·15px 몇 곳
- 인라인 style 267건 — 컴포넌트 재사용이 완전하지 않음(주로 한 번 쓰는 레이아웃 미세 조정)
- 상태 커버리지: empty 5, error 3, 진행 8 존재. hover/disabled는 모바일 터치 화면이라 만들지 않음

다음에 손볼 순서: 어두운 면 토큰화 → 타이포 6단계로 정리 → 인라인 style을 클래스로.
