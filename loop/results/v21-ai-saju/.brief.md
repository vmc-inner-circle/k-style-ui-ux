# 결 — 빌드 공통 메모 (모든 빌드 에이전트가 읽는다)

- 앱 이름 "결". AI는 이름 없이 "결"로 말한다. 말투 "~해요", 단정 대신 "~할 가능성이 커요". 위로하는 밤 말투, 숙련자 대시보드 말투 금지.
- 사실은 `out/journey.md`의 사실 표만 인용. 표에 없는 날짜·숫자·상태를 지어내지 말 것.
- 배지 표(이것만): 구매함 `is-success` · 무료 `is-info` · 이전 정보 기준 `is-warning` · 미리보기 회색(클래스 없음). 시간·순서는 글자로.
- 판촉: "2027 신년운세 리포트"(2027년 1월 31일까지)만 쓸 수 있다(띠 배너 `strip` 또는 블록 하나). 다른 할인·이벤트 금지. 강조색(accent-*) 쓰지 않는다.
- 탭바(한소윤 계정의 탭 첫 화면 home·home-first·saju·ask·match-new·my에만, body `has-tab`): 오늘 `home.html` · 내 사주 `saju.html` · 묻기 `ask.html` · 궁합 `match-new.html` · 마이 `my.html`. 선 아이콘 SVG(stroke 1.75, 24px, currentColor) 인라인. 현재 탭 `aria-current="page"`. home-first는 '오늘' 탭이 현재.
- 김미경 계정 화면(report·stars·stars-done·report-view)은 body에 `text-large`, 탭바 없이 앱바.
- 오행 색(데이터 색으로만, 화면 `<style>`에서 토큰 변수로): 목 `var(--c-success)` · 화 `var(--c-danger)` · 토 `var(--c-warning)` · 금 `var(--c-text-3)` · 수 `var(--c-info)`. 색만으로 뜻을 전하지 않는다 — 항상 "목·화·토·금·수" 글자와 개수 함께. 부적·한지 무늬·붉은 장식 금지.
- 사주 글자는 한글 먼저, 한자는 작게 병기(예: "무술 戊戌"). 풀이 문장은 한자 없이.
- 점수: 숫자로 보이되 막대는 모두 브랜드 색 한 가지, 낮은 점수에 경고색 금지, 점수 옆에 "이렇게 보내세요" 행동 한 줄.
- 인라인 style 금지(예외: CSS 변수만 — 예 `style="--n:4"`, `style="--v:74%"`). 화면 `<style>` 블록은 토큰 변수만 쓰고 hex/rgb 금지, `--c-accent` 금지.
- 사진: `../assets/photos/dawn-sky.jpg`(새벽 하늘 3:4) · `../assets/photos/new-year-sun.jpg`(첫 해 16:9) · `../assets/photos/night-window.jpg`(밤 방 스탠드 16:9). 자리표시 상태여도 경로 그대로.
- 일러스트는 `../assets/fluent/` 목록만(beach calendar car clipboard coffee eyes father hayun hotel idcard invite jieun luggage meal minsu mother phone pill pin plane shoe ticket umbrella walk weather). 사람은 글자 아바타 `avatar is-text`.
- 모든 이동은 실제 `<a href>`. 화면 파일 목록: shared start birth-1 birth-2 home-first home saju term-sheet ask ask-basis match-new match match--done report stars stars-done report-view history my person-edit (.html). 갈 곳이 없는 버튼 금지(탈퇴·로그아웃 같은 범위 밖 동작은 버튼 대신 행 글자만 두거나 my.html로).
- 시장 관례(구조만 참고, 문구·그림·색은 베끼지 말 것): `out/conventions.json`. 시장 리뷰 불만 avoid: A1 결제 뒤 안 열림 → 구매 즉시 열림 / A2 같은 질문에 다른 답 → 근거 표시 / A3 사주 설명만 잔뜩 → 개인 이야기 먼저 / A4 광고 → 없음.
