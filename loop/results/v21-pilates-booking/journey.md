## 범위
- 커버한다: 수강생 앱 전체(S01~S25), 1차는 기본 화면 + 행동 끝 결과 화면.
- 커버하지 않는다: 운영자 웹·강사 수동 출석(범위 외), 1:1 개인레슨 예약(상품만 노출, 스튜디오와 직접 조율), 환불 신청(스튜디오 전화 연결), 태블릿.
- 경계: 둘러보기(비로그인)는 홈·찾기·스튜디오·시간표까지, 예약·구매 누르면 login. 사람 나누기 없음 — 수강생 한 종류.

## 가정 로그
- **팔레트**: Mindbody 시드(초록 #008363) — 라이브러리에 운동·예약 도메인이 없어 웰니스 예약 대표 서비스 색으로 만듦, 산뜻·건강. 대안 컬리(차분 보라)·오늘의집(산뜻 파랑).
- **주요 메뉴(논의점 6)**: 하단 탭 5개 홈·찾기·내 예약·수강권·마이. 잔여 확인이 빈도 4위이고 PRD 문제 2(잔여 헷갈림)가 핵심이라 수강권을 한 번에 닿게 둔다. 정호에게는 홈 첫 블록(다음 수업)만으로 충분하게 만든다. 시장 관례 M1(첫 탭 홈, 마지막 마이)을 따른다. 둘러보기 중에도 같은 탭, 내 예약·수강권을 누르면 로그인.
- **위치 권한(논의점 1)**: 가입 직후 동네 설정에서 "현재 위치로" 버튼을 **누를 때만** 요청(A의 변형) — 첫 화면에서 강제 팝업 없이, 검색도 같은 화면. 도착 확인 출석 때 다시 요청.
- **찾기 기본(논의점 2)**: 목록 기본 + 지도 세그먼트, 마지막 본 방식 기억. 서연이 사진·후기를 비교하고, 시장 관례 M3(사진·이름·종목·거리·가격 카드)를 따른다.
- **리뷰 사진(논의점 3)**: MVP는 사진 없이 별점·좋았던 점·글. 탈의실·타 회원 노출 우려와 검수 부담. 1차 업데이트로 미룸(캔버스 "정한 것"에 공개).
- **기간권 늦은 취소(논의점 4)**: PRD 임시안대로 페널티 없음 + 노쇼만 R4 누적. 정호 화면에는 "기간권은 늦은 취소도 차감되지 않아요" 한 줄.
- **스튜디오별 규정(논의점 5)**: 공통 24시간. 규정 문구를 스튜디오 데이터로 받는 자리(수업 상세 취소 규정 블록)만 같은 모양으로 두어 나중에 열어도 화면이 그대로.
- **체험권(F18)**: 넣는다 — 시장 관례 K1(체험을 회원권보다 앞에)과 서연의 성공한 순간.
