# 여정표 — 동네 필라테스·요가 예약 앱 (수강생용)

## 사람 카드

PRD 3장의 페르소나 A·B·C를 이름 그대로 가져온다.

### A. 김지현 — 핵심 사람
- **누구**: 32세 한국 여성 직장인. 망원동 집 근처 숨필라테스 망원점에서 주 2회 평일 저녁 8시 리포머 수업. 20회권. 야근이 잦아 당일 취소가 종종 있다.
- **처음 오는 이유**: 스튜디오가 "앱으로 예약 받아요"라고 공지해서. 카톡 답장을 기다리다 자리를 놓친 적이 여러 번.
- **그때 마음**: 바쁘고 조급함. 차감될까 봐 불안("그런 말 못 들었는데").
- **알고 싶은 것**
  1. 이번 주 내 수업이 언제 잡혀 있지? → `home`, `my-bookings`
  2. 지금 취소하면 횟수가 차감되나? → `cancel`, `my-bookings`, `class-detail`
  3. 몇 회 남았고 언제까지 써야 하지? → `home`, `tickets`, `ticket-detail`
  4. 자리 났다는데 언제까지 확정해야 하지? → `promote`
- **성공한 순간**: 출근 지하철에서 1분 만에 이번 주 2개 예약, 오후 5시에 "무료 취소 마감 지남, 1회 차감"을 보고 스스로 판단.
- **주로 쓰는 화면**: home, timetable, class-detail, book-confirm, my-bookings, cancel, promote

### B. 박서연
- **누구**: 38세 한국 여성, 아이 등원 뒤 오전 10~12시만 가능. 동네에서 새 스튜디오를 찾는 중.
- **처음 오는 이유**: 이사 와서 믿을 만한 스튜디오를 찾으려고. 사진·후기·강사 이력을 꼼꼼히 본다.
- **그때 마음**: 신중함, 잘못 고르면 돈 아깝다는 걱정. 밤 10시라 여유는 있다.
- **알고 싶은 것**
  1. 오전 10~12시에 수업 있는 가까운 곳은? → `find`, `find-map`
  2. 시설·분위기·후기가 어떤가? → `studio`, `reviews`
  3. 강사가 산전산후·재활을 잘 아나? → `teacher`
  4. 처음인데 체험은 얼마고 바로 되나? → `tickets-shop`, `find`
- **성공한 순간**: 체험권 결제 후 바로 목요일 오전 10시 수업 예약까지 이어짐.
- **주로 쓰는 화면**: find, find-map, studio, teacher, reviews, class-noticket, tickets-shop, pay, pay-done

### C. 이정호
- **누구**: 61세 한국 남성, 재활 목적 소도구 필라테스 주 3회, 3개월 기간권. 앱이 익숙하지 않고 글자 크기·단계 수에 민감. 딸이 가입을 도와줌.
- **처음 오는 이유**: 다니는 바른몸 소도구필라테스가 출석·예약을 앱으로 옮겨서.
- **그때 마음**: 막막함, 잘못 누를까 걱정.
- **알고 싶은 것**
  1. 다음 수업이 언제지? → `home`, `my-bookings`
  2. 도착했는데 출석은 어떻게 하지? → `attend`
  3. 여행 가는 동안 기간이 날아가나? → `pause`, `ticket-detail`
- **성공한 순간**: 데스크 QR 한 번으로 출석 완료, 여행 전 2주 일시정지로 만료일이 늦춰진 걸 확인.
- **주로 쓰는 화면**: home, attend, tickets, ticket-detail, pause

**핵심 사람 = A 김지현** — PRD 2장 문제 1·2·3·4(전화 핑퐁, 잔여 헷갈림, 취소 분쟁, 대기)를 모두 겪는 사람이고, 빈도 1·2위(내 예약 확인·예약)의 주인공. C는 홈의 첫 블록(다음 수업)을 정하는 사람으로 반영.

## 범위
- **커버한다**: 수강생 앱 25개 화면 명세 전부(S01~S25) + 행동의 끝 화면(예약 완료·결제 완료·대기 신청 완료·승급 확정 완료·취소 완료·출석 완료·일시정지 완료·리뷰 등록 완료).
- **커버하지 않는다**: 운영자 웹·강사 계정(PRD 범위 외), 1:1 개인레슨 예약(상품만 노출, 예약은 스튜디오 전화), 환불 신청(스튜디오 전화 연결), 태블릿.
- **경계(추천 결정)**: 리뷰 사진은 1차에서 받지 않는다(논의점 3). 스튜디오별 취소 규정은 열지 않고 공통 24시간(논의점 5) — 단, 규정 문구는 늘 "실제 날짜·시각"으로 계산해 보여 준다.
- **사람 나누기**: 모두 같은 화면. 로그인 전에는 둘러보기(찾기·스튜디오·시간표까지), 예약·구매를 누르면 `login`으로.
