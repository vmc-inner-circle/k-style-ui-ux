# 디자인 시스템 계약 — 파운데이션 · 색 역할 · 부품 토큰 · 레퍼런스 프리셋 v2 (DS1, 2026-10-18 초안)

> **이 문서가 기준이다.** 레퍼런스 8개는 이 그릇에 값만 채운다. 코드(base.css · looks.js · dress.css · 부품 CSS)는 DS2~DS5에서 이 문서대로 바꾼다.
> 배경: [preset-review.md](preset-review.md)(레퍼런스 대조 · 구조 검토).
> 형식(기계 검사용): [`packages/core/tokens/preset.schema.json`](../packages/core/tokens/preset.schema.json).

## 0. 원칙

1. **세 층, 정본은 하나씩**
   - 파운데이션(브랜드와 상관없는 단위) → 색 역할(입력 몇 개에서 계산) → 부품 토큰(몇 칸).
   - 같은 값을 두 곳에서 정하지 않는다. 지금은 모서리가 looks.js SHAPE · dress.css · 모바일 토큰 세 곳에서 정해지는데, 이것을 하나로 모은다.
2. **프리셋 = 입력값 묶음**
   - 레퍼런스는 색 몇 개 · 모서리 · 카드 방식 · 굵기 · 본문 크기만 넣는다. 나머지 역할 토큰은 계산한다.
3. **대비 바닥선은 계산 단계에서 지킨다**
   - 사람이 대비 의견을 낼 일을 없앤다. 막는 것은 lint가 한다(preset-review §6 P2).
4. **브랜드 색 ≠ 버튼 채움 ≠ 강조 글자**
   - 셋을 나눈다. 순수 브랜드 색은 손대지 않고, 버튼 채움과 글자만 바닥선에 맞춘다(Fable 자문, 2026-10-18).
5. **토큰까지만**
   - 부품 모양 자체(버튼 HTML · 새 부품)는 이번 범위가 아니다.

## 1. 파운데이션

### 1-1. 간격 — 지금 그대로
- `--sp-1 … --sp-16` = 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64px.
- 리듬 별칭(`--gutter` · `--space-section` · `--space-block` · `--pad-card` · `--pad-row`)도 그대로 둔다. 토스 · SEED와 같은 방식이다.

### 1-2. 모서리 단계 — 넓힘
| 토큰 | 값 | 지금 |
|---|---|---|
| `--r-0` | 0 | 없음 |
| `--r-1` | 2px | 없음 |
| `--r-2` | 4px | 없음 |
| `--r-3` | 6px | `--r-sm` |
| `--r-4` | 8px | 없음 |
| `--r-5` | 10px | `--r-md` |
| `--r-6` | 12px | 없음 |
| `--r-7` | 14px | `--r-lg` |
| `--r-8` | 16px | 없음 |
| `--r-9` | 20px | `--r-xl` |
| `--r-10` | 24px | 없음 |
| `--r-11` | 32px | 없음(토스 radius-4xl) |
| `--r-pill` | 999px | 그대로 |

- 근거: ko-design-md 레퍼런스 7개의 radius를 합치면 2~32 + full이다.
- 옛 이름(`--r-sm/md/lg/xl`)은 별칭으로 남긴다.
- 부품은 **단계를 직접 쓰지 않고 부품 토큰(§3)을 쓴다**.

### 1-3. 글자 단계 — 이름마다 크기 · 굵기 · 줄간격을 묶는다
| 단계 | 웹 | 모바일 | 굵기 | 줄간격 | 쓰는 곳 |
|---|---|---|---|---|---|
| `display` | 36 | 28 | head | 1.25 | 큰 숫자 · 포스터 |
| `title1` | 28 | 24 | head | 1.3 | 화면 제목 |
| `title2` | 21 | 20 | head | 1.35 | 묶음 큰 제목 |
| `title3` | 18 | 17 | semibold | 1.4 | 묶음 제목 · 카드 제목 |
| `body` | **15 · 16 · 17**(프리셋 `body`) | 같음 | body | 1.55 | 본문 |
| `label` | body와 같은 크기 | 같음 | **button** | 1.25 | 버튼 · 탭 · 칩 글자 |
| `caption` | 13 | 13 | body | 1.45 | 보조 글 |
| `micro` | 12 | 11 | body | 1.4 | 배지 · 탭 글자 · 아주 작은 글 |

- CSS: `--t-<단계>-size` · `--t-<단계>-lh` · `--t-<단계>-weight`.
- 옛 `--fs-*`는 별칭으로 남긴다(`--fs-md` = body …).
- **KRDS 본문 17px**은 프리셋 `body: 17`로 받는다. 큰 글자 토글(toggles.css)은 모든 단계를 한 번에 키운다.
- 자간은 글꼴 세트(looks.js FONTS)가 정한다(그대로).

### 1-4. 그림자 단계 — 밝음 · 어두움
| 토큰 | 밝음 | 어두움 |
|---|---|---|
| `--shadow-0` | none | none |
| `--shadow-1` | 0 1px 2px α .06 | α .30 |
| `--shadow-2` | 0 4px 12px α .08 | α .40 |
| `--shadow-3` | 0 12px 32px α .12 | α .50 |

- 그림자 색은 검정 고정이 아니라 `--c-shadow`(본문 글자 색을 아주 진하게 섞은 값)다. 토스의 남색 기운 그림자도 이 칸으로 받는다.

### 1-5. 움직임
- `--dur-fast` 120 · `--dur-normal` 200 · **`--dur-slow` 320**(새로) · `--ease` · `--ease-enter` · `--ease-exit`(새로).

### 1-6. 화면 틀 · 누르는 면 — 그대로 + 하나
- 웹 1280×800 · 모바일 390×844, 컨트롤 높이 32/40/48, 아이콘 16/20/24.
- **누르는 면 최소** `--hit-min` 44px(새로, KRDS · 애플 기준)을 둔다.

## 2. 색 역할 — 입력 몇 개 → 계산

**입력**(프리셋 · PRD 맞춤 분위기): `mode` · `bg` · `ink` · `brand` · 버튼 색 고르기(`swatches`) · 선택: `status` · `shadowTint`.

| 역할 토큰 | 뜻 | 계산 | 바닥선 |
|---|---|---|---|
| `--c-bg` | 화면 바탕 | 입력 | — |
| `--c-surface` · `-2` · `-3` | 카드 · 한 단계 · 두 단계 | bg에서 섞음(지금 그대로) | — |
| `--c-border` · `-strong` | 선 | bg · ink 섞음 | (선 3:1은 다음 단계) |
| `--c-text` | 본문 | ink를 글꼴 inkMax로 눌러 줌 | 4.5 |
| `--c-text-2` | 보조 글자 | ink → bg 섞음, 모자라면 진하게 | **6** |
| `--c-text-muted` | 흐린 글자 | 같음 | **4.5** |
| `--c-text-disabled` | 비활성(새로) | 섞음 | 없음(WCAG 예외) |
| `--c-placeholder` | 입력 안내(새로) | 흐린 글자와 같게 | 4.5 |
| `--c-brand` | **순수 브랜드 색**(새로) — 강조선 · 고른 탭 밑줄 · 아이콘 · 그림 | 입력 그대로 | **보정하지 않음** |
| `--c-primary` | **버튼 채움** | 고른 버튼 색. 버튼 글자가 바닥선에 못 미치면 OKLCH 밝기만 내림(색감 · 채도 유지). **밝기는 최대 0.08까지만 내리고**, 넘으면 멈추고 경고 | — |
| `--c-on-primary` | 버튼 위 글자 | 레퍼런스: 흰색 고정(채움을 깊게 한다). 맞춤 분위기: 흰색 · 진한 글자 중 큰 쪽 | 레퍼런스 **3** · 맞춤 **4.5** |
| `--c-primary-text` | **강조 글자**(새로) — 링크 · 고른 탭 글자 · 숫자 강조 | 버튼 색을 bg 위 4.5까지 진하게 | 4.5 |
| `--c-primary-soft` · `-soft-fg` | 연한 강조 바탕 · 그 위 글자 | 섞음 + 보정 | 4.5 |
| `--c-<상태>` · `-soft` · `-soft-fg` · `-text` | success · warning · danger · info | 입력 `status` 또는 공통값 → 섞음 + 보정 | 4.5 |
| `--c-focus` | 포커스 링 | 브랜드 색 | (3:1은 다음 단계) |
| `--c-pressed` | 눌림 덮개(새로) | 밝음 rgba(0,0,0,.08) · 어두움 rgba(255,255,255,.10) | — |
| `--c-overlay` · `--c-skeleton` · `--c-shadow` | 덮개 · 불러오는 중 · 그림자 색 | 섞음 | — |

- 레퍼런스(`exact`)의 버튼 글자 3은 **"레퍼런스의 인상을 지키는 선"**이다. WCAG 큰 글자 기준(18.66px 굵게)은 보통 버튼에 해당하지 않는다.
- 공공 납품처럼 엄격한 경우는 하네스 설정 하나로 모든 프리셋을 4.5로 올린다. 프리셋마다 따로 두지 않는다.
- `--c-disabled-opacity` .4(새로)를 둔다. 부품에 박힌 .5를 이 값으로 바꾼다.

## 3. 부품 토큰 — 프리셋이 바꾸는 몇 칸

| 토큰 | 뜻 | 프리셋 입력 |
|---|---|---|
| `--r-control` | 버튼 · 입력 모서리 | `radius.control`(px 또는 `"pill"`) |
| `--r-card` | 카드 · 판 모서리 | `radius.card` |
| `--r-chip` | 칩 · 배지 모서리 | `radius.chip`(없으면 pill) |
| `--card-bg` · `--card-border` · `--card-shadow` | 카드 방식 | `card`: `fill`(회색 바탕 위 흰 판, 선 · 그림자 없음) · `line`(선) · `shadow`(그림자 1~2) |
| `--fw-button` | 버튼 · 라벨 굵기 | `weight.button` |
| `--fw-head` | 제목 굵기 | `weight.head`(없으면 글꼴 세트 값) |
| `--t-body-size` | 본문 크기 | `body` |

- **우선순위**(한 줄 규칙): 파운데이션 기본값 < **프리셋** < **시안 꾸밈**(dress — 구조 쪽 축만: 간격 · 제목 크기 · 배경 무늬) < 사람이 '화면 느낌'에서 고른 값.
- 시안 꾸밈의 `radius` · `cards` 축은 **프리셋이 있으면 쓰지 않는다**. 모서리 · 카드 방식은 프리셋 하나가 정한다(정본 하나).
- 모바일 토큰이 카드 테두리 · 그림자를 강제로 지우던 줄은 **없앤다**(카드 방식은 프리셋이 정한다).

## 4. 레퍼런스 프리셋 v2 — 입력 형식

```json
{
  "id": "toss", "name": "토스 느낌", "why": "회색 바탕에 흰 카드, 굵고 큰 숫자 — 돈·숫자를 다루는 서비스에 어울려요",
  "group": "국내", "mode": "light", "exact": true,
  "bg": "#F2F4F6", "ink": "#191F28", "brand": "#3182F6",
  "swatches": [ { "id": "blue", "name": "파랑", "hex": "#3182F6" }, "… 5개" ],
  "font": "pretendard", "body": 15,
  "radius": { "control": 16, "card": 20, "chip": "pill" },
  "card": "fill",
  "weight": { "head": 700, "button": 700 },
  "status": { "danger": "#F04452" },
  "source": { "repo": "CaesiumY/ko-design-md", "file": "services/toss.tokens.json", "commit": "b594b86", "license": "CC BY 4.0" }
}
```

- **필수**: id · name · why · group · mode · exact · bg · ink · brand · swatches(5) · font · body · radius.control · radius.card · card · source.
- `source: null`은 근거 없음(카카오)이다. 보드 카드에 "참고용"을 붙인다.
- 옛 `shape`는 별칭으로 읽는다: flat → card fill + r 14/20 · soft → line + 10/14 · round → shadow + pill/20 · sharp → line + 6/6. 새 프리셋에는 쓰지 않는다.
- 값마다 출처를 따로 적지는 않는다. 파일 단위 `source` 하나로 둔다(lab tokens.schema의 값별 $source는 v3로 미룬다).

### 4-1. ko-design-md `.tokens.json` → v2 옮기는 규칙 (DS4 스크립트)
- 들어 있는 것: `colors[]`(name · value(oklch) · note · group) · `typography` · `spacing` · `radius` · `elevation`.
- bg = 페이지 바탕 역할 색, ink = 기본 글자, brand = Brand 그룹 대표.
- swatches = 브랜드 + 보조 브랜드 · 상태 중 5개(사람이 고르는 버튼 색 후보).
- radius.control = 버튼 radius, card = 카드 radius. card 방식은 elevation이 쓰이는지와 테두리 규칙으로 정한다.
- 이름 규칙이 브랜드마다 달라서, **브랜드별 짝표**(어느 이름이 bg · ink · brand인지)를 스크립트 옆 JSON 하나에 둔다. 자동으로 못 정한 칸은 비워 두고 lint가 알린다(손으로 채움).
- **hex는 `note`에 적힌 발행값을 먼저 쓴다**(예: 토스 blue-500 note "#3182F6 — TDS 발행값"). note에 없을 때만 looks.js `oklch2hex`로 바꾼다 — oklch를 바꾸면 한 자리씩 어긋난다(#3082F6, DS1 확인). 화면 밖 색(배민 민트처럼 sRGB를 넘는 색)은 잘라 쓰고 경고한다.

## 8. DS1 확인 (2026-10-18)

- `preset.schema.json`에 두 가지를 채워 검사했다. 둘 다 통과했다.
  - 토스: `toss.tokens.json`에서 바탕 grey-100 · 글자 grey-900 · 브랜드 blue-500 · 버튼 색 5개 · 상태 red-500.
  - 카카오: 지금 값, `source: null`.
- 일부러 틀린 값 5가지(이름에 '느낌' 없음 · 본문 14 · 모서리 "round" · 카드 "glass" · 없는 칸)는 모두 잡혔다.
- 드러난 것 두 가지:
  - oklch를 hex로 바꾸면 토스 파랑이 #3082F6로 한 자리 어긋난다 → 발행값(note)을 먼저 쓰기로 §4-1에 적었다.
