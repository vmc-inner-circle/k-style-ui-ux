# 부품 격차 조사 (2026-10-30)

질문: 하네스 결과물이 "단촐하다" — 한국 앱들이 쓰는 부품을 우리가 안 쓰는가?

## 방법
- 레퍼런스 45화면: 토스 6·당근 7·컬리 7·강남언니 6·무신사 6·에이블리 6(uibowl, 무료 범위) + 브랜디 7(uibowl에 없어 App Store). 대부분 앱 스토어용 스크린샷이다.
  - 처음 받은 77장 중 32장 제외(`keep.json`에 남긴 것만 집계): uibowl 페이지의 "추천 앱" 영역에서 딸려 온 다른 앱(GLOWPICK·화해·kmong·ROUNZ·Posty·SOL페이 등)과 그 중복, 앱 화면이 없는 문구·스플래시 이미지.
- 우리 24화면: `showcase/cases.json`의 6개 결과물 × 4화면, 375px 전체 페이지 캡처.
- 같은 분류표(`tagging-brief.md`)로 화면마다 보이는 부품 종류를 태깅(관찰만). 원자료 `*.json`, 집계 `python3 agg.py`.
- 스크린샷 원본은 저작권 때문에 커밋하지 않는다.

## 결과
화면당 부품 종류 수는 같다(레퍼런스 7.0 · 우리 7.0). 차이는 **종류의 구성**이다.

우리가 과하게 쓰는 것: 카드 블록 92%(레퍼런스 22%) · 큰 제목 머리글 67%(7%) · 목록 행 67%(27%) · 하단 고정 버튼 50%(13%) · 탭바 58%(29%).

레퍼런스 3개 앱 이상에서 보이는데 우리는 0%인 것:

| 부품 | 레퍼런스 화면 비율 | 앱 수 | 도메인 무관? |
|---|---|---|---|
| 상단 가로 탭 | 44% | 6/7 | 예 |
| 찜·좋아요 | 31% | 6/7 | 커머스·콘텐츠 |
| 2~3열 상품 격자 | 27% | 5/7 | 커머스 |
| 검색창 | 22% | 6/7 | 예 |
| 정렬·필터 바 | 18% | 5/7 | 목록이 긴 앱 |
| 가로 스크롤 카드 줄 | 16% | 5/7 | 예 |
| 아이콘 격자 메뉴 | 13% | 5/7 | 예 |
| 떠 있는 버튼(FAB) | 9% | 3/7 | 예 |
| 넘기는 배너 | 9% | 3/7 | 예 |
| 얇은 띠 배너 · 동그란 썸네일 줄 · 페이지 점 | 7% | 3/7 | 대체로 예 |

"섹션 제목 + 더보기"도 레퍼런스 27%(6/7)인데 우리는 8%, 사진 썸네일은 44% 대 17%다.

## 한계 (미검증)
- 표본이 작고 대부분 스토어 스크린샷이라 대표 기능 화면 위주로 편향되어 있다.
- 레퍼런스는 커머스·대형 서비스가 많고, 우리 PRD(가족여행·모임·예약·사주)는 소규모 서비스라 일부 차이는 도메인 차이다.
- 태깅은 모델 1회 판정이다.
