# 부품 격차 조사 (2026-10-30)

질문: 하네스 결과물이 "단촐하다" — 한국 앱들이 쓰는 부품을 우리가 안 쓰는가?

## 방법
- 레퍼런스 77화면: uibowl(무료 = 앱당 최신 패턴 3개) 토스 9·당근 12·컬리 12·강남언니 11·무신사 11·에이블리 13, 브랜디는 uibowl에 없어 App Store 스크린샷 9.
- 우리 24화면: `showcase/cases.json`의 6개 결과물 × 4화면, 375px 전체 페이지 캡처.
- 같은 분류표(`tagging-brief.md`)로 화면마다 보이는 부품 종류를 태깅(관찰만). 원자료 `*.json`, 집계 `python3 agg.py`.
- 스크린샷 원본은 저작권 때문에 커밋하지 않는다.

## 결과
화면당 부품 종류 수는 비슷하다(레퍼런스 6.7 · 우리 7.0). 차이는 **종류의 구성**이다.

우리가 과하게 쓰는 것: 카드 블록 92%(레퍼런스 19%) · 목록 행 67%(18%) · 큰 제목 머리글 67%(16%) · 하단 고정 버튼 50%(9%).

레퍼런스 7개 앱 중 5개 이상에서 보이는데 우리는 0%인 것:

| 부품 | 레퍼런스 화면 비율 | 앱 수 | 도메인 무관? |
|---|---|---|---|
| 상단 가로 탭 | 44% | 7/7 | 예 |
| 검색창 | 27% | 7/7 | 예 |
| 넘기는 배너 + 페이지 점 | 26% | 6/7 | 예 |
| 아이콘 격자 메뉴 | 25% | 7/7 | 예 |
| 가로 스크롤 카드 줄 | 22% | 6/7 | 예 |
| 떠 있는 버튼(FAB) | 21% | 7/7 | 예 |
| 찜·좋아요 | 18% | 6/7 | 커머스·콘텐츠 |
| 2~3열 상품 격자 | 16% | 5/7 | 커머스 |
| 얇은 띠 배너 | 14% | 6/7 | 대체로 예 |
| 정렬·필터 바 | 10% | 5/7 | 목록이 긴 앱 |
| 툴팁·코치마크 | 9% | 5/7 | 예 |

"섹션 제목 + 더보기"도 레퍼런스 26%(6/7)인데 우리는 8%다.

## 한계 (미검증)
- 표본이 작고 uibowl 무료 범위가 "최신 패턴" 위주라 편향이 있을 수 있다(예: 토스는 게이미피케이션 화면이 많음).
- 레퍼런스는 커머스·대형 서비스가 많고, 우리 PRD(가족여행·모임·예약·사주)는 소규모 서비스라 일부 차이는 도메인 차이다.
- 태깅은 모델 1회 판정이다.
