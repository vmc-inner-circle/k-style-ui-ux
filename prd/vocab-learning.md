# 출퇴근 10분으로 영어 단어를 쌓는 경험을 설계해주세요

안녕하세요. 아래 과제를 확인하고 결과물을 제출해주세요.

## 1. 배경

**토익·회화·해외 출장처럼 목적은 다르지만 매일 짧게라도 영어 단어를 외우고 싶은 20~40대 직장인·대학생**을 위한 단어 학습 앱을 만듭니다.

단어 앱을 시작하는 사람은 많지만 2주를 넘기는 사람은 적습니다. 처음에는 의욕이 넘쳐 하루 50개를 고르지만, 며칠 밀리면 복습할 단어가 수백 개로 쌓이고, 그 숫자를 보는 순간 앱을 열기 싫어집니다. 반대로 외운 단어는 실제 문장에서 다시 만나지 않으니 금방 잊습니다. 결국 "나는 단어 앱이랑 안 맞아"라며 그만둡니다.

## 2. 핵심 유저스토리

1. **바쁜 직장인으로서**, 출퇴근 지하철에서 10분만 써도 오늘 할 몫을 끝냈다는 느낌을 받고 싶다. 며칠 빠져도 다시 시작하는 게 부담스럽지 않았으면 좋겠다.
2. **시험을 앞둔 학습자로서**, 시험일까지 남은 기간에 맞춰 무엇을 얼마나 외워야 하는지 알고 싶다.
3. **외운 단어를 쓰고 싶은 사람으로서**, 단어 뜻만이 아니라 실제로 어떤 장면·문장에서 쓰이는지 그림과 예문으로 기억하고 싶다.

## 3. 사용자들의 상황

- 하루 학습 시간은 대부분 5~15분이고, 출퇴근·점심시간처럼 한 손으로 폰을 드는 상황이 많습니다.
- 목적에 따라 필요한 단어가 다릅니다(토익 비즈니스 어휘, 여행 회화, 업무 이메일).
- 학습을 3일 이상 빼먹는 일이 한 달에 두세 번은 생깁니다.
- 뜻을 아는 것과 문장에서 알아보는 것, 직접 쓸 수 있는 것은 서로 다른 단계입니다.
- 이미 아는 단어를 계속 다시 보는 것을 지루해합니다.

## 4. 기능 요구사항

1. **목표 설정**: 학습 목적과 하루 분량(또는 시험일)을 정하면 오늘 할 몫이 정해져야 합니다.
2. **오늘의 학습**: 새 단어와 복습 단어를 한 흐름 안에서 학습하고, 단어마다 그림·예문·발음을 볼 수 있어야 합니다.
3. **기억 확인**: 외웠는지 스스로 판단하거나 퀴즈로 확인하고, 결과에 따라 다음 복습 시점이 달라져야 합니다.
4. **밀린 학습 다시 시작하기**: 며칠 빠졌을 때 쌓인 복습을 부담 없이 다시 시작할 수 있어야 합니다. 어떻게 덜 부담스럽게 만들지는 여러분이 판단해주세요.
5. **내 단어장과 진도**: 외운 단어·헷갈리는 단어를 모아 보고, 얼마나 쌓였는지 확인할 수 있어야 합니다.

## 5. 조건

- 한 손 조작과 짧은 사용 시간을 전제로 설계해주세요.
- 단어마다 그 뜻을 떠올리게 하는 그림이 들어가야 합니다. 필요한 이미지·아이콘·더미 텍스트는 직접 조달해주세요.
- 기존 단어 앱들을 참고하되, 그대로 베끼지 말고 위 문제(§1, §2-1)를 실제로 해결하는 구조를 보여주세요.
