# 회사 대화를 기기 밖으로 내보내지 않고 쌓는 회의 녹음 앱을 설계해주세요

안녕하세요. 아래 과제를 확인하고 결과물을 제출해주세요.

## 1. 배경

사내 AI 에이전트를 만드는 회사가 늘고 있습니다. 에이전트는 문서와 메신저는 읽지만, 실제 결정이 내려지는 **회의**는 읽지 못합니다. 회의 결정은 참석자의 기억이나 누군가의 메모에만 남습니다.

클라우드 회의록 서비스를 쓰면 되지만, 회의 원본을 새 외부 업체 서버에 보내는 일은 보안 검토를 통과하기 어렵습니다. 실제로 기업 교육 설문에서 AI 사용을 꺼리는 이유 1위가 "보안·정보 유출 걱정"이었고, 회의록에 AI를 쓰는 사람 대부분이 "데이터 보안 제약"을 어려운 점으로 꼽았습니다.

그래서 **iPhone 안에서 녹음과 글 변환을 끝내고, 결과는 회사가 정한 사내 주소 한 곳으로만 보내는** 회의 녹음 앱을 만듭니다. 앱은 요약을 만들지 않습니다. 요약·결정사항·할 일은 회사 시스템에 쌓인 원문 위에서 회사가 쓰는 AI가 만듭니다. 이 앱이 지킬 것은 "회의 원문이 빠짐없이, 정확하게, 회사 밖으로 새지 않고 도착하는 것"입니다.

## 2. 핵심 유저스토리

1. **회의에 들어가는 직원으로서**, 회의가 시작될 때 앱을 찾아 열지 않고 한 번에 녹음을 시작하고 싶다. 회의가 끝났는데 깜빡하고 안 끄더라도 녹음이 몇 시간씩 이어지지 않았으면 좋겠다.
2. **회의에 들어가는 직원으로서**, 녹음이 제대로 되고 있는지 회의 중에 슬쩍 확인하고 싶다. 하지만 회의에 집중해야 하니 화면을 오래 들여다보고 싶지는 않다.
3. **회의를 마친 직원으로서**, 녹음이 글로 바뀌어 회사 시스템에 잘 도착했는지만 알면 된다. 실패했다면 무엇을 하면 되는지 알고 싶다.
4. **회사 보안·AX 담당자로서**, 이 앱이 무엇을 어디로 보내는지 직접 확인하고 싶다. 회사가 정한 주소 말고는 회의 내용이 밖으로 나가지 않는다는 것을 눈으로 보고 싶다.

## 3. 사용자들의 상황

- 회의는 하루 2~6건, 한 건에 15분~2시간입니다. 회의실 대면 회의가 대부분이고, 휴대폰을 책상 위에 올려 둡니다.
- 녹음을 시작하는 순간은 대개 회의가 이미 시작된 직후입니다. 앱 아이콘을 찾고 여러 단계를 누르는 사이 앞부분을 놓칩니다.
- 회의가 끝나도 바로 다음 일정으로 이동하느라 녹음 끄는 것을 자주 잊습니다.
- 녹음이 끝난 뒤 글로 바꾸는 데는 회의 길이의 약 1/6이 걸립니다(60분 회의 → 약 10분). 그동안 사용자는 다른 일을 합니다.
- 글로 바꾸는 음성 인식 모델은 처음 한 번 내려받아야 합니다(약 630MB). 크기를 보여 주고 사용자가 받기를 누른 뒤에만 받습니다.
- 회사 시스템이 받을 주소(Webhook URL)는 보통 회사 담당자가 알려 주고, 직원이 처음 한 번 넣습니다. 주소를 넣지 않으면 회의 데이터는 기기 밖으로 전혀 나가지 않습니다.
- 녹음 중에는 기기 안에서 바로 만든 실시간 자막을 볼 수 있지만, 정확도가 낮은 미리보기입니다. 녹음이 끝난 뒤 다시 변환한 결과가 정본이고, 회사로는 정본만 보냅니다.
- 휴대폰이 마이크 권한을 잃었거나 소리가 아예 안 들어오는 일, 회사 서버가 잠시 꺼져 전송이 실패하는 일이 실제로 생깁니다.

## 4. 기능 요구사항

1. **빠른 녹음 시작**: 앱을 열지 않고도 잠금 화면·제어 센터·홈 화면 위젯 같은 곳에서 한 번에 녹음을 시작할 수 있어야 합니다. 녹음 중에는 앱 밖에서도 녹음 중임을 알 수 있어야 합니다.
2. **녹음 중 확인**: 경과 시간, 소리가 들어오고 있는지, 실시간 자막(미리보기)을 확인할 수 있어야 합니다. 시작 몇 초 동안 소리가 전혀 안 들어오면 알려 주되 녹음은 멈추지 않습니다.
3. **무음 자동 정지**: 말소리 없이 정해진 시간(기본 10분, 1~15분 조절)이 지나면 녹음이 스스로 멈춰야 합니다. 멈추기 전에 곧 멈춘다는 것을 알 수 있어야 합니다.
4. **회의 목록과 결과**: 지난 회의를 날짜순으로 보고, 각 회의의 상태(변환 중·전송됨·실패 등)를 알 수 있어야 합니다. 회의를 열면 제목·날짜·길이와 변환된 원문 전체를 볼 수 있어야 합니다. 말소리가 없었던 회의는 그렇다고 알려 줍니다.
5. **회사로 보내기**: 변환이 끝나면 사람 손 없이 회사가 정한 주소로 원문을 보내야 합니다. 실패하면 자동으로 다시 시도하고, 사용자에게는 녹음과 원문이 기기에 그대로 있다는 것과 다음 시도 시각을 알려 줍니다.
6. **전송 기록**: 이 앱이 기기 밖으로 보낸 모든 요청(회의 전송, 연결 확인, 음성 인식 모델 다운로드)을 시각·주소·결과와 함께 볼 수 있어야 합니다. 보안 담당자가 이 화면 하나로 "무엇이 어디로 나갔는가"를 확인할 수 있어야 합니다.
7. **처음 시작하기**: 처음 실행할 때 이 앱이 무엇을 하는지, 녹음 동의 안내(대화에 참여하는 동안만 녹음, 참석자에게 알리기, 회사 규정 따르기), 마이크 권한, 음성 인식 모델 받기를 거칩니다. 회사 주소는 나중에 설정에서 넣을 수 있습니다.
8. **설정**: 회사 주소 입력과 연결 확인, 무음 자동 정지 시간, 전송 기록, 오픈소스 라이선스·개인정보처리방침.

## 5. 조건

- iPhone 앱입니다. 화면 크기는 iPhone 기준으로 설계해주세요.
- 첫 버전에는 계정·로그인·동기화·검색·화자 구분·앱 안 요약이 없습니다.
- 앱 화면의 말은 한국어입니다.
- 필요한 이미지·아이콘·더미 텍스트는 직접 조달해주세요. 회의 원문 더미는 실제 회사 회의처럼 자연스러운 한국어 대화로 만들어주세요.
- 기존 회의록 앱(클로바노트, 티로, Otter 등)을 참고하되, 그대로 베끼지 말고 위 상황(§2-1 시작과 종료, §2-4 보낸 것 증명)을 실제로 해결하는 구조를 보여주세요.
